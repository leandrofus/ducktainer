# Security policy

## Supported versions

Security fixes go into the latest release. Older releases do not get fixes, so update to the latest version (`ducktainer version` prints yours).

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: go to the repository's **Security** tab and choose **Report a vulnerability**. Include:

- the ducktainer version and how you installed it;
- what an attacker can do, and what they need first (network access, an account, a host);
- the steps to reproduce it, or a proof of concept that does not harm other systems.

Reports stay private until a fix is released. We will reply as soon as we can, keep you informed while we work on it, and credit you in the release notes unless you prefer not to be named.
